# Vazirmatn web fonts

Source: Google Fonts CSS API, Vazirmatn v16, weight axis 400–900. Original family: https://github.com/rastikerdar/vazirmatn

Licensed under SIL Open Font License; see OFL.txt. Arabic and Latin WOFF2 subsets retain all currently used characters and broad Persian/Arabic/basic Latin coverage, with all shaping features and variable weight support. Latin extended is the original Google Fonts subset. Font family and weight metrics are preserved. Font display uses swap; only Arabic is preloaded.
